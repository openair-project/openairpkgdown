# openairpkgdown 0.0.6

- Refreshed the theme with a new stylesheet (`extra.scss`): a translucent navbar with a coloured top strip, tidier typography, code blocks, tables, callouts and table of contents.

- The 'packages' menu is now called 'Toolkit', with a new 'Resources' section linking to the openair book and GitHub. The current package is highlighted in the menu.

- Added a footer linking to the openair project.

- Accent colours now follow the light/dark switch.

- Each package can set its own accent colour with `template: bslib: primary`.

- Added a theme demo article for previewing changes to the template.
